# 충전소 상세 정보 개선

2026-10-21. 사용자 첨부 화면과 [무공해차 통합누리집 공식 지도](https://www.ev.or.kr/nportal/monitor/evMap.do)의 철원역사문화공원 상세를 직접 확인하여 반영했다.

| 정보 | 화면 처리 | 데이터 기준 |
| --- | --- | --- |
| 전체 상태 | 충전 대기·충전 중·점검/예약 등·확인 필요 4개 요약 | 기존 신선도 판정 그대로 사용. 오래된 마지막 보고를 현재 사용가능으로 세지 않음 |
| 충전기별 정보 | ID, 커넥터, 출력, 완속~초급속 구간, 상태 확인 시각 | 공공 API에 실제 존재하는 필드 |
| 요금 | 회원/비회원 독립 표시, 공표 요금/공시 범위의 출처 구분 | 실제 연결된 `fees.json`의 운영사 ID와 출력 일치. 비회원 미제공 시 회원가 복제 금지 |
| 실시간 가격 | 미연결임을 안내 | 공식 화면에 실시간 단가가 보인다고 일반 충전소 API에 그 필드가 존재한다고 가정하지 않음 |
| 공공 요금 기준 | 접어 보는 5개 출력 구간 참고표 | 기후부 운영 공공충전시설의 공표 회원 요금만 사용. 민간 운영사 단가로 오인시키지 않음 |

| 이용 안내 | 운영시간·주차요금·출입 조건·전화·시설 구분·비고 | 미제공 정보를 무료/제한 없음으로 대체하지 않음 |
| 용어 설명 | kW/kWh, 커넥터, 회원/로밍, 충전 비용 계산, 확인 시각 | 접어 보는 도움말로 구성 |
| 상세 기록 | 제조사·설치연도·충전방식·상태 변경·마지막 충전 기록 | 현재 충전 시작은 최근 상태가 충전 중이며 미래 시각이 아닐 때만 표시 |

`data-status.html`에도 실제 연결된 요금 운영사·회원/비회원 항목 수와 수집 확인 시각을 추가했다. 현재 저장소의 공표 요금 자료는 ME 운영사 회원 5개 구간이며, 민간 충전기별 실시간 가격과 비회원 가격을 새로 수집했다고 주장하지 않는다. [요금 자료 범위와 수집 기준](DATA_COLLECTION.md)을 유지한다.

수집기에는 충전기별 `location`, `detailAddress`를 보존하도록 추가했다. 이 항목은 다음 정상 수집 결과 게시에서 원본 캐시에 존재하는 값부터 채워지며, 미제공 값은 다음 전체 수집을 따른다. 기존 스냅샷은 충전기별 층수와 단일 충전소 위치를 이용하고, 여러 위치가 섞였을 때는 충전기별 위치 미확인으로 안내한다. 이 화면 변경을 위해 전국 재수집을 강제하지 않았다.

상세 도움말·기록의 펼침 상태, 상세 스크롤과 비용 입력을 갱신 중 유지한다. 상세를 지도 가림 영역으로 등록하여 선택한 마커가 넓어진 패널을 피하도록 했다. 좌측 검색·목록 높이와 광고 슬롯은 유지한다.
