# 충전소 상세 정보 정확성·UI 검토

2026-10-21 KST. 사용자의 요청에 따라 별도 UI 전문가 에이전트와 코드 기반으로 정보 순서·표현·접근성·좁은 화면 배치를 검토하고, 수정 후 독립 재검토를 받았다. 실제 화면을 보았다는 의미의 시각 검수는 수행하지 않았다.

| 발견 사항 | 반영한 동작 |
| --- | --- |
| 전부 상태 미확인인데 대기 0기가 강조됨 | 확인 불가·확인된 대기 없음·일부 미확인·등록 정보 없음 문구를 분리. 0기 타일은 중립 색상 |
| 전체 집계와 현재 검색 조건의 수가 혼동됨 | 커넥터·출력 조건에 맞는 수와 충전소 전체 상태를 구분. 개별 카드에도 현재 충전기 조건 일치 여부 표시 |
| 대기 필터가 상태 미확인 기기를 모집단에서 제거함 | 주요 상태 메시지는 대기 필터를 제외한 호환 커넥터·출력 모집단으로 계산. 대기 필터 일치 수는 별도 표기 |
| 요금이 없는데 위에서 가격 확인을 안내함 | 실제 연결된 요금이 없으면 충전소 단위 미확인 안내. 회원·비회원·출력별 연결 수를 실제 값으로 표시 |
| 민간 충전소에서 공공 요금표를 해당 충전소 요금으로 오독할 가능성 | ME 운영 충전소에만 공공 회원 요금표 제공. 민간 운영사에는 해당 표를 표시하지 않음 |
| 모든 카드에서 미확인 요금 박스·같은 설명 반복 | 전부 미확인인 경우 한 번만 안내. 일부 충전기만 가격이 있으면 가격 없는 카드에 미확인 한 줄 표시 |
| 용어 설명이 충전기보다 먼저 나오며 기록이 길어짐 | 제목·주소·지도 링크 → 상태 → 방문 조건 → 충전기 → 시설·문의 → 요금 → 계산기·도움말 순서. 과거 기록은 기본 접힘 |

| 모호한 편의제공 여부의 의미 확대 위험 | 기타 시설 등록 정보로 접어 제공하고 편의 종류·접근성을 해당 플래그만으로 알 수 없음을 명시 |

독립 재검토에서 발견한 대기 필터 모집단과 부분 요금 누락 문제까지 수정했다. 기존 지도 자동 조회·마커 갱신·좌측 목록·고정 광고 슬롯은 이 변경의 대상이 아니다.

## 검증 범위

- 필수 `npm run check`, `npm test`, `npm run build`, `git diff --check` 수행.
- 상태의 분할과 신선도, 빈 목록, 전체/일부 미확인, 필터를 적용한 혼합 커넥터, 대기 필터 중 미확인, 부분 요금 연결, 운영사·회원 구분을 자동 검사한다.
- 실제 게시된 철원역사문화공원 스냅샷을 실제 app.js에 주입한 VM 통합 검증 9개 흐름: 공유 상세 열기, 충전기 3개, 층수, 민간 운영사의 공공 가격 미표시, 요금 미확인, 비용 입력 보존, summary 포커스·펼침 보존, 같은 충전소 스크롤 유지, 다른 충전소 상단 이동. DOM은 모의 객체이며 브라우저 동작·시각 검수가 아니다.
- 320px·390px 배치에 적용되는 CSS 규칙을 코드로 검토했다. 연결 브라우저가 이 대화의 originating browser context를 요구하며 접근에 실패했으므로 실제 모바일 렌더링·스크린샷·터치 검증은 미완료다. 자동 검사나 코드 검토를 시각 검수로 보고하지 않는다.
- 배포 후 리비전·필수 페이지·수집 현황·실제 gzip 지역 데이터의 건수 일치 검증은 배포 검사로 별도 수행한다. 로컬의 인증 없는 빌드 결과를 실데이터 수집 성공으로 표시하지 않는다.
