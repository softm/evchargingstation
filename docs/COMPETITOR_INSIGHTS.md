## 실제 동작

- 속도는 원본 `outputKw`가 확인된 충전기만 구간에 포함한다. 출력 미확인은 특정 속도로 추정하지 않는다.
- 충전기 많은순은 전체 커넥터 개수가 아니라 현재 조건에 맞는 물리 충전기 수를 사용한다. 같은 복합 커넥터 충전기를 중복 집계하지 않는다.
- 인근 대안을 누르면 기존 충전소명 검색과 즐겨찾기 조건을 해제하고 대안의 목록·지도·상세를 연동한다. 다른 차량·이용 조건은 유지한다.
- 비용 계산의 입력값은 현재 브라우저 세션에서 충전소별로 유지한다. 다른 운영사의 단가를 자동으로 대입하지 않는다. 주차비·로밍 할증·할인은 별도로 확인한다.
- 새 필터와 정렬 조건은 기존 충전소 공유 링크에 포함한다.

## 후속 데이터가 필요한 기능

| 기능 | 필요한 근거 |
| --- | --- |
| 시·군·구 단계 탐색 | 수집된 `districtCode`와 검증된 행정구역 명칭 테이블 연결 |
| 최근 설치순 | 실제 설치일 또는 지속 수집한 최초 발견일. 설치연도만으로 최근 개통일을 만들지 않음 |
| 현장 제보·후기 | 자체 등록·수정 이력과 현장 확인 시각. 경쟁 사이트 후기나 평점을 복사해 앱 데이터로 넣지 않음 |
| 운영사·카드별 요금 자동 비교 | 검증된 사업자 코드 매핑, 회원/비회원·로밍/출력별 요금과 기준일 |

## 검증 범위

`npm run check`, `npm test`(JavaScript 40개 + Python 31개), `npm run build`, `git diff --check`를 통과했다. 경계 출력·동일 충전기 조건·미확인 운영시간·인근 거리/접근성/신선도·정렬·비용 입력을 검사했다. 운영 배포와 실제 브라우저 화면 검증은 PR 병합 후 별도로 확인해야 한다.
