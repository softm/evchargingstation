1. 서비스 개요

충전한눈은 전기차 충전소의 위치, 충전기 종류, 충전 출력, 이용 가능 상태 등 공개·연계 데이터를 지도에서 확인할 수 있도록 제공하는 서비스입니다.

2. 위치정보 사용

사용자가 위치 권한을 허용하면 현재 위치 주변의 충전소를 찾고 지도 중심을 맞추기 위해 기기의 현재 위치를 사용합니다. 위치 권한을 허용하지 않아도 지역 또는 충전소를 직접 검색할 수 있습니다.

충전한눈 Android 앱은 백그라운드 위치 권한을 요청하지 않습니다. 위치정보는 현재 화면에서 주변 충전소 탐색 기능을 제공하기 위한 용도로만 사용합니다.

앱은 사용자의 현재 위치를 자체 서버에 계정 정보와 결합하여 영구 저장하는 기능을 제공하지 않습니다.

3. 기기 내 저장정보

즐겨찾기한 충전소, 검색·지도 상태와 같은 일부 설정은 브라우저 또는 WebView의 로컬 저장소(localStorage)에 저장될 수 있습니다. 사용자는 저장 해제 또는 앱·브라우저 데이터 삭제를 통해 이를 제거할 수 있습니다.

4. 외부 서비스

지도 표시는 네이버 Maps 또는 Leaflet·OpenStreetMap을 이용할 수 있고, 웹 콘텐츠는 GitHub Pages를 통해 제공됩니다. 서비스 제공 과정에서 각 사업자에게 IP 주소, 브라우저·기기 정보 등 통신에 필요한 정보가 전달될 수 있습니다.

5. 광고

충전한눈은 카카오 AdFit 광고를 표시합니다. 광고 제공·측정 및 부정 이용 방지를 위해 IP 주소, 기기·브라우저 정보, 쿠키 또는 온라인 식별정보, 광고 노출·클릭 정보가 카카오에 의해 처리될 수 있습니다.

충전소 검색어, 즐겨찾기, 위치 정보와 충전소 선택 내역은 광고 맞춤화를 위해 카카오에 별도로 전달하지 않습니다. 광고 차단, NO-AD 또는 오류가 발생하면 빈 광고 공간을 제거합니다.

6. 데이터 보관 및 삭제

충전한눈이 자체적으로 운영하는 사용자 계정 기능은 현재 제공하지 않습니다. 기기 내 로컬 저장정보는 사용자가 앱 데이터 또는 사이트 데이터를 삭제하면 제거할 수 있습니다.
